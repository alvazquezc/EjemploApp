# Prompts de imagen para la presentacion multiagente

Cada prompt esta pensado para una imagen 16:9 full-bleed. La presentacion PPTX final ya contiene una imagen por diapositiva; estos prompts sirven para regenerar o cambiar el estilo manualmente en ChatGPT.

## Diapositiva 1

Infografia 16:9 full-bleed para una presentacion tecnica en espanol. Mensaje central: mas alla de los tokens teoricos. Mostrar transicion de teoria de tokens hacia una aplicacion real que revela flujo interno, flexibilidad y resiliencia. Estilo SaaS tecnico, fondo claro, acentos teal azul ambar, texto grande legible, sin logos.
